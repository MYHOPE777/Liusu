# 浏览器独立悬浮脚本

这个脚本不需要安装 Chrome 扩展。它在当前已经登录的千川主播大屏标签页内运行，只读取页面已经渲染的“实时公屏” DOM，并把统计面板固定在页面右上角。

## 先用 URL 定位直播间

直接打开 `standalone/launcher.html`，粘贴完整的主播大屏 URL，点击“定位直播间”。启动页会校验域名、页面路径和 `live_room_id`，然后在浏览器新标签打开对应直播间；它不会尝试跨域读取直播页。定位成功后，启动页会直接提供 `overlay-runner.js` 和 `bookmarklet.txt` 的打开入口，不需要再到项目文件夹里查找。

## 使用方式：书签一键启动（推荐）

1. 在 `launcher.html` 中把“千川流速启动”按钮拖到 Chrome 书签栏，只需一次。
2. 打开已登录的主播大屏页面。
3. 点击书签栏里的“千川流速启动”。页面右上角出现“千川流速 · 独立悬浮”即启动成功。

重复点击同一书签会关闭旧面板再启动一个新面板。刷新页面后再次点击书签即可；统计事件会保存在当前房间的浏览器本地存储中。

如果浏览器不允许拖拽书签，也可以打开 `bookmarklet.txt`，新建书签后把整行内容作为网址保存。DevTools Snippet 仍可作为开发调试备用入口，但普通使用不需要它。

## 使用方式：书签脚本

将 `standalone/bookmarklet.txt` 中的一整行复制为 Chrome 书签的网址。打开主播大屏后点击该书签即可启动；再次点击会关闭面板。Chrome 如果自动删除 `javascript:` 前缀，需要在书签编辑框中手动补回。

脚本不访问直播接口、不上传昵称、不读取隐藏数据。没有找到公屏时面板仍会显示，并提示“未找到实时公屏”。
