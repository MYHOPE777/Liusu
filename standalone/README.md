# 浏览器独立悬浮脚本

这个脚本不需要安装 Chrome 扩展。它在当前已经登录的千川主播大屏标签页内运行，只读取页面已经渲染的“实时公屏” DOM，并把统计面板固定在页面右上角。

## 先用 URL 定位直播间

直接打开 `standalone/launcher.html`，粘贴完整的主播大屏 URL，点击“定位直播间”。启动页会校验域名、页面路径和 `live_room_id`，然后在浏览器新标签打开对应直播间；它不会尝试跨域读取直播页。

## 使用方式：Chrome DevTools Snippet

1. 打开已登录的主播大屏页面。
2. 按 `Option + Command + I` 打开开发者工具。
3. 切换到 `Sources`，在左侧选择 `Snippets`。
4. 新建一个 snippet，把 `/Users/tangsir/千川流速/standalone/overlay-runner.js` 的全部内容复制进去并保存。
5. 按 `Command + Enter` 运行。页面右上角出现“千川流速 · 独立悬浮”即启动成功。

重新运行同一脚本会关闭旧面板再启动一个新面板。刷新页面后需要再次运行脚本；统计事件会保存在当前房间的浏览器本地存储中。

## 使用方式：书签脚本

将 `standalone/bookmarklet.txt` 中的一整行复制为 Chrome 书签的网址。打开主播大屏后点击该书签即可启动；再次点击会关闭面板。Chrome 如果自动删除 `javascript:` 前缀，需要在书签编辑框中手动补回。

脚本不访问直播接口、不上传昵称、不读取隐藏数据。没有找到公屏时面板仍会显示，并提示“未找到实时公屏”。
